# Round 29 — Italian UI (i18n) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to
> implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** the whole Heureum UI available in Italian (and English), chosen from the user's profile or,
when unset, from the browser — zero dependencies, no flash, user data untouched.

**Architecture:** a hand-rolled typed i18n layer in `frontend-next/lib/i18n` (per-area catalogues,
`I18nProvider`, `useT`/`useFormat`/`useLocale`, cookie-mirrored locale read by the root layout),
then a sweep of every page/component area replacing literals with `t()` and dates/numbers with
`useFormat()`; a small backend change recognises Italian issue-type names.

**Tech Stack:** Next.js 16 App Router, React 19, TanStack Query, TypeScript strict, `Intl` APIs,
Playwright; Go for the backend task.

**Spec:** `docs/superpowers/specs/2026-11-03-round-29-i18n-design.md`

**Interfaces (Produces — every later task uses exactly these):**
- `type Locale = "en" | "it"`; `type Plural = { one: string; other: string }`;
  `type Catalog<T>` = same keys as `T`, `string` leaves, `Plural` where `T` has a plural object
  (so `it` missing/extra keys fail `tsc`); `type MessageKey` = union of dotted paths of `en`
  (e.g. `"layout.nav.projects"`).
- `resolveLocale(input: { user?: string | null; cookie?: string | null; browser?: string | null }): Locale`
  and `const LOCALE_COOKIE = "heureum_locale"` in `lib/i18n/resolve.ts` (pure, no React).
- `I18nProvider({ initialLocale: Locale, children })`; `useT(): (key: MessageKey, params?: Record<string, string | number>) => string`
  — `{name}` interpolation; when the value is a `Plural`, `params.count` selects the form via
  `Intl.PluralRules(locale)`; unknown key at runtime returns the key (never throws).
- `useLocale(): { locale: Locale; setLocale(l: Locale): void }` — `setLocale` updates context,
  `document.documentElement.lang` and the cookie (`path=/; max-age=31536000; samesite=lax`).
- `useFormat(): { date(d: string | Date, opts?: Intl.DateTimeFormatOptions): string; dateTime(d): string; relative(d): string; number(n: number): string }`
  — `date` default `{ day: "numeric", month: "short", year: "numeric" }`; `relative` via
  `Intl.RelativeTimeFormat(locale, { numeric: "auto" })` picking seconds/minutes/hours/days/months/years.
- `LocaleSync`: reads the current user with the SAME query key the app already uses for
  `profile.me()` (grep it), resolves `{ user: me.locale, cookie, browser: navigator.language }` and
  calls `setLocale` when different.
- Notification titles: `notifications.types.{assignment,comment,mention,sprint_started,sprint_completed,status_change}`
  with `{key}` from `link` (`/issues/KEY` or `/browse/KEY`); unknown type → stored `title`.
